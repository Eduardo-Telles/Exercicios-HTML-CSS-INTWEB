## 🎯 Sobre este repositório

Aqui ficam os exercícios da disciplina de introdução à web e o que pratico por conta própria. O objetivo é registrar minha evolução, praticar uma estrutura de código limpa (HTML semântico, CSS organizado, nomes claros) e manter tudo em um só lugar.

Estou atualizando aos poucos, então novos exercícios aparecem com frequência.

## 📂 Como está organizado

introducao-web/

│   └── exercicio-02/

> Os nomes acima são um exemplo. Ajuste conforme as pastas que você realmente tem e apague este aviso depois.

## ▶️ Como visualizar

Não precisa instalar nada além de um navegador.

1. Baixe o repositório (**Code > Download ZIP**) ou clone:
   ```bash
   git clone https://github.com/Eduardo-Telles/NOME-DO-REPOSITORIO.git
   ```
2. Abra a pasta do exercício que quiser ver.
3. Dê dois cliques no arquivo `index.html` (ou no arquivo principal do exercício) para abrir no navegador.

Se usa o VS Code, a extensão **Live Server** atualiza a página automaticamente enquanto você edita.
